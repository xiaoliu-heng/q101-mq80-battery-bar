MQ80 Firmware Lab 2.1
Q101 / MQ80 原生 macOS 离线固件测试工具

打开
解压后双击 MQ80 Firmware Lab 2.1.app。当前包适用于 Apple Silicon，目标系统为 macOS 13 及以上；仅在当前 Mac 上实测，未验证 Intel 或其它系统版本。
界面完全使用 SwiftUI / AppKit，未内嵌网页，不启动 HTTP 服务。Python / Unicorn 已随应用打包，无需另外安装。
关闭窗口或退出应用后，固件引擎也会退出。

第一次使用
1. 顶部选择“Fn+B 侧灯电量条 v2”。
2. 工作台右侧拖动电量，点击“Fn＋B 查询电量”，侧灯按电量显示颜色和长度。时钟会自动继续；约三秒后恢复原侧灯效果。原侧灯设为关闭时就会熄灭。
3. 用继续 / 暂停控制时钟。暂停时灯和倒计时冻结。普通按键或调节环境不会自动暂停。
4. 时钟右侧“…”菜单可进入全关灯 / 普通空闲休眠检查点。2.4G 下进入等待唤醒后，单击虚拟 A，检查主机字符 a 和报告。
5. 打开“灯效预览”，点击“播放波浪”等预设，观察动画；右侧可调主灯效果、亮度、速度，以及侧灯模式和亮度。
6. 打开“场景与回归”，运行全部回归。电量条 v2 的当前基准为 10 项通过。

五个工作区
工作台：84 键矩阵、实体键盘输入、组合键、Fn＋B、主灯原始帧、虚拟主机、电源计数和原生追踪表。单击键帽模拟按住 50 ms 后松开；开启组合键后先选择，再点“发送组合”。“松开所有键”同时清空选中键帽、实体按住的键和虚拟 Fn，并显示反馈；取消勾选“组合键”也会自动执行这些释放。
灯效预览：原固件生成的连续 RGB 帧，键帽与原始索引双视图，侧灯按 84–92 编号显示。键帽灯位是几何表推导，尚未逐灯实物校准。部分按键触发效果仍需补齐运行时状态。
场景与回归：10 个内置场景、JSON 编辑 / 导入 / 导出、断言、双镜像对比、OTA / CRC 四分支。场景在独立虚拟机运行，完成后可载入末态继续调试。右侧对照镜像也是 OTA 的候选固件。
运行时检查：只读虚拟内存、通用寄存器、执行统计与完整状态；可保存读出的文本。
建模覆盖：逐项说明哪些机器码真实执行，哪些外设响应来自模型。

实体键盘测试
1. 点击“使用实体键盘”，或按 ⇧⌘K。直接按住 Shift、Ctrl、Option、Command 与字母等组合；键帽同步高亮，松开时发送释放状态，不需要逐个点选组合。
2. 默认“右 ⌘ → Fn”，按右 Command＋B 即为虚拟 Fn＋B。如果键盘没有右 Command，勾选“按住 Fn”后直接按 B。实体键盘自身的 Fn 一般由键盘内部处理，不会发给电脑。
3. 按 ⌘. 或点击“停止键盘输入”退出。切换窗口、切离工作台、文件对话框和重置时自动释放。仅在本窗口拥有输入焦点时接收普通键盘事件，不要求全局“输入监控”权限。
4. macOS 已保留的快捷键、媒体键可能先被系统处理。Caps Lock 按瞬时按键模拟；系统的按住自动重复不当作第二次物理按下。每次矩阵改变至少推进 35 ms 虚拟时间完成扫描、消抖和报告；不能用它测量实体输入延迟。

时钟
实时预览：按墙钟推进，空闲时合并调度；不执行跳过的 IRQ，适合灯效预览。存在输入、报告队列或 PM 等待时返回离散执行。
严格仿真：逐次执行假定 1 ms IRQ 与任务调度；速度显示为实际运行倍率，三秒指虚拟时间。休眠计时、首键时序和回归使用这一模式。
步进 1 ms 不是单条 CPU 指令。步进、休眠检查点、重置、切换固件 / 连接 / 键位检查点会暂停。
休眠检查点预置空闲计数后执行真实分支，不代表已实测经过 4.5 秒或十分钟。
JSON jump 只跳跃时钟；advance 执行离散调度；preview 是明确标记的灯效合并步骤。录制会合并相邻时间片。
灯效初始化和动画计数由固件代码执行；10 ms 动画节拍由模型提供，不代表实物准确帧率。

固件与键位
内置 MQ80 官方 V0109（126292 字节）和 Fn+B 侧灯电量条 v2（126756 字节），顶部固件菜单可直接切换，默认选择 v2，不需要另行导入。这次 App 更新未修改两个 BIN。导入其它镜像要求 CS836B 应用 BIN，检查 KNLT、codesize、OTA 对齐与 CRC。不能导入 EXE 升级工具。
固定地址配置依赖 V0109；CRC 正确不等于其它镜像可以兼容。
默认 Fn 层是历史只读 VIA 调查保存的 Q101 键位，作为虚拟 NVM 输入；没有新读取键盘或证明出厂默认值。右侧“故障注入与键位”可选镜像默认表，Fn＋B 可能随之不同。
切换固件、连接或键位会重建运行环境，先保存需要保留的快照。未知指令或未支持外设会停止并显示错误，避免把缺少建模当作通过。

快照与导出
顶部时钟箭头菜单可保存 / 载入快照、导出操作录制与完整追踪。分享图标或 ⌘S 导出运行报告。位置由原生文件对话框选择。
快照保留 RAM、MMIO、Flash、通用寄存器 / PC、队列、调度与 PM 暂停上下文，只接受相同固件 SHA256 与配置。不修改 BIN。未序列化特权 CSR 和完整中断控制器，不是任意指令位置的完整芯片快照。
恢复后的录制依赖原始快照，不能独立当作从冷启动开始的场景。
追踪最多 3000 项，主机报告 / 发包各最多 1000 项；导出标出被截断数量。工作台显示最近 100 条追踪。

快捷键与数据
⌘O 导入固件；⌘S 导出报告；⇧⌘S 保存快照；⌘R 继续 / 暂停；⇧⌘B 查询电量；⌘Q 退出。
⌘1～⌘5 切换工作区；⌥⌘A 发送虚拟 A。“仿真”菜单也可进入休眠检查点、播放波浪 / 常亮、运行全部回归。
⇧⌘K 开始实体键盘输入；捕获输入期间应用快捷键会作为待测组合发送，⌘. 专用于退出捕获。操作菜单或文件对话框前先停止输入。
快照、导出与测试启动会等待之前的按键和环境修改完成，避免快速连按时保存到旧状态。
导入镜像与任务报告在 ~/Library/Application Support/MQ80 Firmware Lab/ 的 firmware / reports。
native-runtime.log 为引擎诊断。导出文件由你选择位置。全部处理在本机，无遥测、HID、串口、IOKit 设备访问或刷写入口。

能力边界
保留真实 RV32 / Andes 指令、启动复制 / BSS、GPIO 扫描 / 消抖 / HID、RGB / 电量条、2.4G PM 准备 / 返回与封包 / ACK、USB 报告、BLE 应用通知和 OTA END / CRC。
接收器、主机响应、PM 返回、时钟、电量缓存 / 充电输入与 1 MB NOR 为模型。
没有完整上电、PLL / 模拟电路、ADC / 放电曲线、DMA / RF 中断、无线空口、BLE 控制器 / 配对 / 加密、USB 枚举 / 控制传输、bootloader / 强制恢复 / 掉电恢复模型。
软件通过不能证明真机功耗、首键空口必达或刷写失败后必然恢复。当前发布的测试和实测界面证据见 VALIDATION.json；旧 1.0 / 1.1 证据保留原版本名称。
